遥控器

方向键、音量键支持长按连续发送；每个按键都是独立的请求，服务端不会自动重复。

信号源

这些动作 ADB 没有 keyCode，只能走 UDP 9900。电视待机或断网时不可用；UDP 无应答，发送后以画面为准。

电源

电源键走 ADB（keyCode 26，待机/唤醒切换）；关机键走 UDP 9900。两者执行前都会二次确认，待机后电视断网，Web 无法再控制。
